# Mu Reforge - the live servers, played through this machine's proxy

Local stand-in for the production list (deploy/reforge/serverlist.md): the same groups, but the
connect server is dialled through `bun run proxy` on this machine instead of wss://ws.mureforge.com.
Used with VITE_PINNED_WORLD=on in .env.local, which plays the first world of this list only.
